# exp3_fixed_ch3 — 第三轮:固定拓扑 3 信道(拥塞)★ 主实验(结论已被 exp4 推翻,见下)

> ⚠️ 本轮 3 种子的"unfixed −70%"结论在 exp4 的 10 种子封口检验中**被推翻**
> (p=0.91/0.99,无差异)。种子间训练结果双峰导致小样本假象。
> 本目录数据保留作为证据链一部分,引用时须以 exp4 的 10 种子结果为准。

## 条件
- 拓扑:固定 variant 25(与 exp2 同一确定化场景)
- 信道:CHANNEL_NUM=3(拥塞设定;同频冲突致命,SINR>2 门槛)
- 观测:34 维,干扰 log 归一化
- 臂:none / fixed_d3 / fixed_d5 / unfixed_1-4,各 3 种子(s1-s3)
- 训练:4000 episodes;每 100 eps 做 20 episode 贪心评估

## 结果(eval 末 5 点,3 种子)
| 臂 | eval_reward | eval_success | vs none |
|---|---|---|---|
| none | 10.39±8.04 | 13.67±0.81 | — |
| fixed_d3 | 12.29±7.81 | 13.73±0.90 | +18.3%(噪声内) |
| fixed_d5 | 11.16±2.37 | 13.73±0.38 | +7.4%(噪声内) |
| unfixed_1-4 | 3.12±7.98 | 12.81±0.86 | **−70.0%** |

## 结论
1. **随机延迟致伤(−70%),固定延迟无害**——伤害来自延迟的不可预测性
   (非平稳观测破坏马尔可夫性),而非滞后深度(fixed_d5 平均更旧却无害);
   与 RDC 论文(NeurIPS 2025)核心论断一致,任务卸载域首次复现;
2. 拥塞是延迟致伤的使能条件(exp2 证明 CH=6 下无效应)→ 交互效应;
3. n=3 统计功效不足、缺剂量效应曲线、2×2 因子范围不匹配 → exp4 封口。
