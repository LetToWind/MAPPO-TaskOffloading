# exp4_sealing — 第四轮:封口实验(统计功效 / 剂量效应 / 严格 2×2)

## 设计
- A 组(统计功效):CH=3,{none, unfixed_1-4} 补种子 s4、s5(与 exp3 的 s1-s3 合并为 5 种子)
- B 组(剂量效应):CH=3,unfixed [1,2] / [1,3] / [2,4] × s1-s3
  (与已有 unfixed [1,4] 一起构成剂量曲线;[2,4] 与 [1,3] 均值同为 2.5 但方差更大,
  用于分离"均值效应"与"方差效应")
- C 组(2×2 补全):CH=6,unfixed [1,4] × s1-s3
  (exp2 的随机臂是 [1,3],补 [1,4] 使因子范围与 exp3 严格对齐)

## 统一条件
- 固定拓扑 variant 25(同一确定化场景)、34 维 log 归一化观测、4000 episodes、
  贪心评估同前;运行脚本 scripts/run_experiments.py,由本目录 logs/ 收日志

## 运行
```
conda activate py37tf
cd MADDPG_Discrete
python scripts/run_experiments.py --group exp4_sealing --max-parallel 8
python scripts/analyze_results.py seal
```

## 结果(10 种子封口后,含 exp4b_seeds 补充的 s6-s10)

**核心结论被推翻:unfixed [1,4] 的退化在 10 种子下消失。**

| 对比 | n | reward | success | 显著性 |
|---|---|---|---|---|
| none | 10 | 5.29 ± 10.98 | 13.10 ± 1.12 | — |
| unfixed [1,4] | 10 | 5.81 ± 8.14 | 13.09 ± 0.88 | p=0.91 / 0.99,无差异 |

前 5 种子的 −63.9% 是**种子运气**:none 前五均值 14.0、后五均值 −3.4;
unfixed 前五 5.1、后五 6.6。种子间训练结果双峰(收敛 ~14-22 或崩塌 ~−9),
方差远大于延迟效应。

### 唯一幸存信号
unfixed [2,4](均值延迟 3 + 随机性):success 11.99 vs none 13.10(−8.4%),
唯一 reward 为负的臂(−5.42);而同均值的 fixed d=3 无害(13.73, n=3)。
n=3 不足以下结论,需更多种子验证。

## 失败根因分析(重要,指导下一步)

环境里被延迟的量是**准静态的**:`Compute_Interference_2` 只用固定距离矩阵 +
确定性路径损耗,**无信道衰落**——只要信道分配不变,干扰逐帧不变,
z(t-d) ≈ z(t),延迟信息无损。拥塞只是提高了错选信道的代价,没有让
"新鲜度"本身产生价值。要让延迟真正致伤,环境需要**决策相关且时变**的
信息(如快衰落信道、动态任务到达)。详见 实验规划文档.md 的修订。
