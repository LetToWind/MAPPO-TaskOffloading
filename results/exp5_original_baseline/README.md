# exp5_original_baseline — 原始基线代码多种子方差测量(未改一行训练代码)

## 设计
- 对象:原始 `train_mappo.py`(26 维观测、CH=6、固定拓扑 variant 25),
  仅通过环境变量关闭 SPMARL/动态拓扑(`USE_SPMARL=0 USE_DYNAMIC_TOPOLOGY=0
  FIXED_CURRICULUM=0`),5 个"种子"(原代码不设任何随机种子,每次运行自然独立;
  且场景构建器无种子 → 每次运行随机重抽场景,这也是原始代码行为的一部分);
- 训练:4000 episodes/种子;评估:最终 checkpoint 在**同一确定化评估场景**
  (seed 990001)上 100 episode 贪心评估(scripts/eval_original.py);
- 运行:scripts/run_original_baseline.py(顺序执行 + 崩溃自动重试,29.5 分钟)

## 结果

| 种子 | 训练尾段 reward(自身场景) | 贪心评估 reward(公共场景) | success |
|---|---|---|---|
| s1 | 51.98 | 44.52 | 17 |
| s2 | 39.12 | 23.95 | 15 |
| s3 | 52.44 | 15.05 | 14 |
| s4 | 67.01 | 63.31 | 19 |
| s5 | 65.54 | 23.46 | 15 |
| **均值±std** | **55.22 ± 11.43(CV 21%)** | **34.06 ± 19.63(CV 58%)** | **16.0 ± 2.0** |

## 结论

1. **方差是原始代码固有的,不是我引入的**:训练层面 CV 21%,跨场景评估 CV 58%
   (种子间 reward 跨度 15.1~63.3,4 倍);我此前在 CH=3 观测到的双峰不稳
   是该固有方差在更难设定下的放大;
2. 方差的两个来源:①训练随机性(TF 无种子,±11);②**场景过拟合**——每次运行
   随机抽不同场景,策略过拟合自身场景(s3 训练 52.4 → 公共场景评估仅 15.1;
   s5 65.5 → 23.5);
3. 对照:我 exp2 的改法(同场景确定化 + log 归一化 + 邻居负载,贪心评估)
   none 臂 61.73±17.42,均值反而高于原基线自身场景训练值(55.2)——
   观测改动没有劣化学习;
4. **对历史结论的警示**:单种子下 reward 差异 <30~40 的任何对比
   (含 MAPPO vs MADDPG)都在种子噪声范围内,不可作为结论依据。
